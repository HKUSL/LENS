### **Threat Model:**
- **Attack Assumption:**
  - On S6a, the normal sender of an `Insert-Subscriber-Data-Request` is the **HSS** and the victim receiver is the **MME**. We assume the MME is misconfigured so an Internet attacker can impersonate the HSS, open a Diameter connection to the MME, and send forged IDRs that the MME accepts as valid subscriber-data updates.

- **Attacker Capability:**
  - The attacker can actively send crafted `Insert-Subscriber-Data-Request` messages on its own Diameter connection and receive the corresponding answers. The attacker knows the target subscriber identity needed for `User-Name`, but cannot observe or alter legitimate HSS<->MME traffic and has no extra NAS/GTP/PGW control beyond what follows from the MME accepting the forged S6a request.

### **Exploitability Analysis:**
- `Subscription-Data.APN-Configuration-Profile.APN-Configuration.Service-Selection` is the APN identity string for one provisioned `APN-Configuration` entry. The MME stores it as the subscribed APN name for that `Context-Identifier` and later uses it for APN authorization, default APN selection, and downstream PDN session establishment.

- The field-specific causal chain is:
  1. The attacker sends a forged IDR from the spoofed HSS role to the MME.
  2. Inside the chosen `APN-Configuration`, the attacker sets `Service-Selection` to an unknown or unroutable APN name.
  3. The MME stores that string as the subscribed APN for the default context.
  4. On a later attach or PDN Connectivity procedure, the MME treats the UE-requested APN as unsubscribed, selects the poisoned default APN, or fails APN resolution toward SGW/PGW.
  5. The subscriber-visible result is PDN connectivity failure, attach/default bearer failure, or rejection of a previously valid APN.

- The incremental harm comes from this string itself: changing `Service-Selection` changes which APN the MME believes is provisioned for that entry. The attacker does not need a static served-party address or PGW control. An unknown APN name is enough to poison authorization state. The value persists in the MME subscriber context until a later legitimate overwrite.

### **Attack Procedure:**
- Craft a forged `Insert-Subscriber-Data-Request` on S6a from the spoofed HSS identity to the target MME, using the victim subscriber's `User-Name`.
- Include `Subscription-Data` -> `APN-Configuration-Profile` -> one `APN-Configuration` with `Context-Identifier`, numeric `PDN-Type`, `EPS-Subscribed-QoS-Profile`, `AMBR`, and `Service-Selection` set to a malicious APN name.
- Expected success condition: the MME accepts the IDR and later attach/PDN procedures fail APN authorization or default PDN setup because the stored APN name is not a subscribed, routable APN.
