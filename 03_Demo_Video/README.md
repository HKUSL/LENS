# LENS Demonstration Videos

This directory contains six representative demonstration videos showing security impacts observed during the implementation-level assessment of LENS.

## View the Demonstrations

- **Local:** Open [`index.html`](index.html) in a browser.
- **Online:** Visit the [hosted demonstration page](https://hkusl.github.io/LENS/).

The demonstration page presents the testing environments and all six videos in a single browser-based interface.

## Directory Contents

- [`Test Environments/`](Test%20Enviroments/) — figures illustrating the isolated environments used for implementation-level assessment.
- **Hosted videos** — the six video files are stored externally and loaded by the demonstration page.
- [`index.html`](index.html) — the local browser-based demonstration page.

## Featured Demonstrations

All six videos were recorded in the isolated Commercial Core Network A testing environment.

### Security Consequences

The first five videos demonstrate representative impacts from each consequence category reported in the paper:

1. **Service Disruption**
2. **Service Degradation**
3. **Information Leakage**
4. **Battery Depletion**
5. **Subscriber Tracking**

### Representative Attack

The sixth video demonstrates the **persistent rogue-network attachment** attack described in Section 5.3 of the paper.

> All demonstrations were conducted in an isolated testing environment separated from operational networks.
