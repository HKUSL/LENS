IEEE S&P 2027

When Core-Network Elements Become Reachable:
Field-Level Exploitability Analysis in Diameter

This page presents our demonstration videos.

Testing Environments

The demonstrations are conducted in isolated testbeds separated from operational networks, following the implementation-level assessment setup described in the paper. The evaluated environments include an open-source EPC/IMS testbed and two anonymized commercial core-network deployments.

Commercial Core Network A

An anonymized commercial deployment supporting both S6a and Cx, with HSS, MME, IMS, and commercial eNB components.

Open-Source Testbed

Open5GS supports the S6a interface, Kamailio supports the Cx interface, and srsRAN provides the radio access side.

Commercial Core Network B

An anonymized commercial Cx testbed used to validate IMS-related impacts against a separate commercial implementation.

These demonstration videos are intended solely for security research and responsible disclosure. Do not use against any network or system without authorization.
